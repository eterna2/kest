# Workflow & Automation Rules

This document defines the rules for using and maintaining workflows in the `kest` toolkit.

## Workflows & Automation
AI Agents MUST prioritize established workflows over ad-hoc commands:
- **Discovery**: Search `.agents/workflows/` for task-specific guides before starting complex operations.
- **Turbo Protocol**: Use `// turbo` or `// turbo-all` for commands that are safe to auto-execute.
- **Memorialization**: Convert new, reproducible multi-step procedures into workflow files to preserve repository "muscle memory."
